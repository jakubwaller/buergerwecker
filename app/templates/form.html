FAQ

{% if lang == 'en' %}

Does this book appointments?

No. It checks and sends you an email. Booking is on you, on the city's own site.

Is this fair?

Fairer than the status quo. Without it, appointments go to whoever hits F5 all day or pays a slot reseller. This is free and the code is public (AGPLv3).

Do the cities know?

Yes, all of them got an email. Polling is deliberately slow and subscriptions expire after 90 days.

{% else %}

Bucht das Tool Termine?

Nein. Es schaut nach und schickt dir eine Mail. Buchen musst du selbst, auf der Seite der Stadt.

Ist das fair?

Fairer als der Status quo. Ohne das Tool bekommt die Termine, wer den ganzen Tag F5 drückt oder einen Termin-Weiterverkäufer bezahlt. Das hier ist kostenlos und der Code ist öffentlich (AGPLv3).

Wissen die Städte davon?

Ja, alle wurden angeschrieben. Die Abfrage-Intervalle sind bewusst zurückhaltend und Anmeldungen laufen nach 90 Tagen automatisch aus.
